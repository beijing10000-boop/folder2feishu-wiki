# Folder2Feishu Drive 界面系统化审计与重构说明

## 本轮目标

在不修改迁移逻辑、接口、数据库、权限、路由和五步操作流程的前提下，将现有界面收敛为一套适合桌面运维场景的企业级设计系统。视觉目标以 `docs/ui-audit/selected-visual-target.png` 为准。

## 审计发现

1. `styles.css` 同时保留旧深色主题、浅色覆盖层和后续补丁，级联关系复杂，同一组件在不同页面呈现不一致。
2. `v3.css` 再次覆盖主样式，字体、边框、间距、响应式断点和导航布局存在重复定义。
3. 旧版装饰性网格、发光色和多重边框抢占注意力，不符合高密度运维平台的阅读习惯。
4. 页面标题、卡片标题、技术标签和辅助文案的字号梯度不稳定。
5. 主操作、普通操作和危险操作的视觉层级不够稳定，停止任务容易与普通按钮并列竞争。
6. 配置、盘点、预检、计划和运行页的内容宽度、卡片留白和双栏比例不统一。
7. 长目录、长路径、迁移队列和实时日志需要统一的截断、局部滚动和密度策略。
8. 状态主要依赖颜色，部分区域缺少同步的中文状态文字。
9. 任务运行页的当前阶段、当前对象、结果、控制按钮、分片进度和日志虽已具备，但视觉分组不统一。
10. 多组重复媒体查询提高维护成本，并容易在 1366 px 和 1024 px 桌面窗口出现覆盖顺序问题。

## 选定设计规范

- 风格：浅色、专业、克制的企业运维控制台。
- 字体：优先使用 Microsoft YaHei UI / PingFang SC / Noto Sans SC；计数和标识使用等宽字体。
- 色彩：蓝色用于主操作和当前步骤；绿色表示成功；橙色表示需要关注但可继续；红色仅用于失败、阻断和危险操作。
- 间距：以 8 px 为基础节奏，页面区块间距 16–24 px。
- 容器：8 px 圆角、1 px 中性边框、极轻阴影，不使用渐变、发光或装饰网格。
- 导航：64 px 顶栏内放置五步流程；窄桌面窗口时自动换为顶栏下方的横向步骤栏。
- 数据密度：目录树、表格、队列和日志使用紧凑行高、长文本省略和独立滚动区域。
- 反馈：所有异步按钮保留忙碌态；任务状态同时显示阶段、数量、结果、当前对象、心跳和控制入口。

## 已修改页面与组件

- 公共框架：应用栏、五步流程导航、页面标题区、当前项目卡片、底部运行状态栏、消息提示。
- 配置页：必要配置总览、六项验证状态、应用凭据、授权身份、上传速率、来源与云盘目标路径、安全增量策略。
- 盘点页：扫描命令区、实时进度、指标卡、目录树、本地完整性问题和下一步交接。
- 预检页：摘要指标、阻断/通过提示、预检矩阵和目录抽样。
- 差异计划页：计划确认状态、动作统计筛选、差异表格、安全增量决策链和启动操作。
- 运行对账页：任务状态、运行控制、总进度、接口调用、分片进度、实时迁移日志、文件队列和审计导出。
- 运行页信息层级：总进度和上传接口调用已并入顶部任务状态容器，不再以两个孤立卡片占用下一行。
- 公共组件：面板、标题、按钮、表单、开关、验证徽标、指标卡、空状态、目录树、状态色和响应式规则。

## 样式治理结果

- 主样式从 5,126 行收敛为单一约 700 行设计系统。
- 删除已不再加载的 `frontend/src/v3.css`。
- `frontend/src/main.tsx` 只加载一份样式文件。
- 清除旧深色主题、渐变、装饰网格和互相覆盖的重复规则。
- 保留现有 React 组件、接口调用、状态管理、权限校验和业务流程。

## 回归结果

- TypeScript 类型检查：通过。
- 前端单元/交互测试：13 项全部通过。
- 前端生产构建：通过。
- 后端测试：167 项通过，1 项按既有条件跳过；35,000 文件和 5,051 目录的独立规模验收通过。
- 迁移执行器默认并行工作线程由 4 个调整为 6 个；全局飞书写入速率仍保持 5 QPS 上限。
- 页面任务状态和实时日志轮询继续计入接口指标，但成功且小于 1 秒的本机轮询不再刷屏写入运行日志；错误、慢请求及迁移日志不受影响。
- 当前环境的内置浏览器连接初始化失败后，改用同一代码的独立 Playwright 浏览器会话完成五步流程验收；新版证据截图为 `docs/ui-audit/v4-config.jpg`、`v4-scan.jpg`、`v4-preflight.jpg`、`v4-plan.jpg`、`v4-run.jpg`。

## 未处理问题

- 本次正式发布证据采用 1600 px 宽桌面视口；1920×1080、1366×768 和 1024×768 的逐分辨率截图矩阵不作为本次发布阻断项，后续可继续补充。
- 移动端不在本项目范围内；窄屏规则仅保证桌面小窗口可访问，不定义移动端专用交互。
